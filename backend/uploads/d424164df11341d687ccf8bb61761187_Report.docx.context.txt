Abstract
The Blood Donor Web Application is designed to connect blood donors with recipients efficiently. In emergency situations, finding the right blood type quickly can be a matter of life and death. This system addresses the limitations of traditional manual methods by providing a centralized online platform for donor registration and search.
The application allows donors to register their details, including name, blood type, contact number, and city. Users in need of blood can search for available donors based on blood type and location. This significantly reduces the time taken to find suitable donors.
Administrators have a dedicated dashboard to manage donor information. They can add, update, or delete donor records, ensuring that the database remains accurate and up-to-date. The system also provides security measures to protect sensitive user data.
The web application promotes community participation by encouraging people to register as donors. It also assists hospitals, clinics, and emergency services in maintaining a ready-to-access donor database for urgent requirements.
In conclusion, the Blood Donor Web Application is a practical solution that saves time, enhances efficiency, and facilitates life-saving blood donations. Its simple interface and structured database make it easy to use for donors, users, and administrators alike.

The proposed web-based system addresses these limitations by creating a centralized platform for donor registration, management, and search.
System analysis also considers feasibility, which ensures that the proposed system can be implemented effectively with the available resources, technology, and time.

In the existing manual system:
Donors are registered physically in hospitals or blood banks.

Admins have limited control over donor records and no centralized view.
Drawbacks of Existing System:
Time-consuming donor search.
High chance of errors in donor information.
Difficulty in tracking donor availability.
Limited reach to potential donors.

System Design












System Design
System Design is the process of defining the architecture, components, modules, interfaces, and data for a system to satisfy specified requirements. For the Blood Donor Web Application, system design ensures the application is efficient, scalable, secure, and user-friendly.

1. Architectural Design
The system follows a 3-tier architecture:
Presentation Layer (Frontend)
Built using HTML, CSS, and JavaScript.
Provides user interface for donors, recipients, and administrators.
Allows users to register, login, search donors, and view results.
Application Layer (Backend)
Implemented using PHP.
Handles business logic like user authentication, donor search, and session management.
Processes requests and communicates between frontend and database.
Data Layer (Database)
Uses MySQL (via XAMPP) to store donor information securely.
Tables include donor_info, admin, and user.
Structured relational database ensures data integrity and fast query processing.

2. Database Design
The database design is critical for managing donor information efficiently.


Main Tables:
1. donor_info
2. admin
3. user (optional for recipients)

Key Features of the Database:
Relational structure ensures accurate mapping between donors, users, and admins.
Indexing on blood_type and city improves search performance.
Foreign keys maintain referential integrity between tables.
          









                       
Use Case Design

Actors:
Admin: Manages donors, monitors database, and generates reports.
Donor: Registers and updates personal details.
Recipient/User: Searches for donors and requests blood.
Main Use Cases:
Register Donor: Donor submits personal details.
Admin Login: Admin authenticates and accesses dashboard.
Search Donor: Recipient searches donors by blood type and city.
Manage Donors: Admin adds, edits, or deletes donor records.
Use Case Diagram:
Admin → Login → Manage Donors
Donor → Register → Update Info
Recipient → Search Donors
 
4. Data Flow Design (DFD)
Level 0 (Context Level):
System interacts with Admin, Donors, and Recipients.
Data flows between users and the system, with requests processed by the backend and stored/retrieved from the database.
Level 1 (Detailed DFD):
Donor Registration Module: Captures donor details → stored in donor_info table.
Search Module: Recipient inputs criteria → system queries database → results displayed.
Admin Management Module: Admin adds/updates/deletes donor records → database updated.
 
5. Interface Design
Admin Panel:
Dashboard showing total donors, search options, and add/delete donor functionality.
Donor Registration Page:
Form to capture name, blood type, phone, and city.
Validation for required fields and correct formats.
Search Page:
Input fields for blood type and city.
Display table of matching donors with contact details.
User Interface Features:
Responsive design using CSS for desktop and mobile access.
Navigation links for easy access to different modules.

6. Security Design
Authentication: Admin and users login using secure credentials.
Session Management: Maintains active session to prevent unauthorized access.
Password Hashing: Passwords stored using secure hashing functions (e.g., PHP password_hash()).
Input Validation: Prevents SQL injection and ensures data integrity.

7. Conclusion
The system design ensures a structured, efficient, and secure application for managing blood donors. The combination of a relational database, PHP backend, and responsive frontend provides a complete solution to manage, search, and connect donors and recipients effectively.
The design also allows future scalability, such as integrating notification systems, mobile applications, or advanced analytics for donor trends.

User Manual












User Manual for Blood Donor Management System

1. Introduction
The Blood Donor Management System is a web-based application designed to connect blood donors with people who urgently need blood.
It helps users register as donors, search for available donors, and manage blood requests efficiently.
The system improves emergency response and ensures that blood is available when needed.

2. System Requirements
Hardware
Minimum 4GB RAM (8GB recommended)
Intel i3/i5 or higher processor
Stable internet connection
Software
Operating System: Windows / Linux / macOS
Browser: Google Chrome / Mozilla Firefox
For local development: XAMPP / Python / Node (depending on your backend)
MySQL or MongoDB database installed (project dependent)

3. User Registration & Login
Steps to Register
Open the Blood Donor Application in your browser.
Click “Sign Up” from the menu.
Enter required details:
Full Name
Email Address
Password
Phone Number
City
Blood Group
Click Register.
Login Procedure
Go to Login page.
Enter your registered email and password.
Click Login to access your dashboard.

4. Adding/Updating Donor Information
After login, open the Dashboard.
Click “Update Profile” or “Add Donor Info”.
Upload or update:
Name
Blood Group
Contact Number
City / Address
Availability Status
Click Save to update the donor database.

5. Searching for Donors
Go to the Search Donor section.
Select the required blood group.
Enter city or location.
Click Search.
The system displays:
Donor Name
Phone Number
Blood Group
City
Availability
Users can directly contact the donor.

6. Features & Navigation
Home
Overview of the Blood Donor System and purpose.
Dashboard
Manage your profile, donation status, and personal details.
Search Donor
Find donors by blood group and location.
Request Blood
Submit an emergency blood request if no donor is available.
Profile
View or edit your account and donation history.
About
Information about the project’s purpose and technology used.
Logout
Securely signs out the user.

7. Security & Privacy
All user data is encrypted and safely stored.
Only registered users can view donor details.
Passwords are protected with hashing/encryption.
Personal data is stored securely in the database.
System follows basic data privacy principles.

8. Troubleshooting
Issue: Cannot Log In
Check if email and password are correct
Use “Forgot Password” if available
Issue: Cannot Search Donor
Ensure you selected a valid blood group
Check internet connection
Issue: Donor Not Visible
Donor may be marked as Not Available
Admin may have restricted the profile

9. Contact Support
For help or technical support, contact:
📧 support@blooddonorapp.com
(Or the email your project team uses)
You can also access the Help Center inside the application.

CONCLUSION
The Blood Donor Management System was developed to simplify the process of connecting blood donors with recipients in urgent situations. Traditional methods of searching for donors are often slow, unreliable, and unorganized. This system overcomes these challenges by providing a fast, secure, and user-friendly platform.
Through this project, essential concepts such as web application design, database management, authentication, and CRUD operations were implemented. The system allows administrators to manage donor details efficiently, ensuring that accurate and updated information is always available.
The application successfully demonstrates how technology can support life-saving activities. By digitizing donor information and making it accessible, the project reduces delays during emergencies and encourages more people to participate in blood donation.
This project can be enhanced in the future by adding features such as SMS alerts, location-based donor matching, email notifications, and mobile app integration. Overall, the project achieves its goal of providing a reliable, efficient, and meaningful solution for blood donor management.
